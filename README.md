# 📡 局域网双向传输工具

一款简洁高效的局域网文件传输工具，支持电脑与移动设备、电脑与电脑之间的实时消息和文件互传。

## ✨ 功能特性

- 📱 **跨设备通信**：支持电脑与移动设备、电脑与电脑之间的双向消息和文件传输
- 🌐 **局域网传输**：仅在本地局域网内传输数据，无需互联网
- 📤 **大文件支持**：支持大文件高速传输，带实时进度条显示
- 📁 **文件夹传输**：自动压缩后发送文件夹，保留目录结构
- 🔄 **实时消息**：支持文字消息的实时发送和接收
- 🖥️ **PC 发现**：自动发现局域网中的其他 PC 设备，一键连接
- 📲 **扫码连接**：移动设备扫码即可快速连接，无需手动输入地址
- 🔒 **隐私安全**：不上传任何数据到远程服务器，保护用户隐私

## 🚀 快速开始

### 前置条件

推荐直接使用依赖清单（含 PC 互联所需的 WebSocket 客户端）：

```bash
pip install -r requirements.txt
```

如需手动安装：

```bash
pip install flask flask-socketio python-socketio python-engineio simple-websocket websocket-client gevent qrcode Pillow requests PyQt5
```

### 运行方式

```bash
# 直接运行
python main.py

# 可选：指定下载路径
python main.py --download-path D:/Downloads
```

### 使用步骤

程序默认监听 5000 端口；若被占用会自动顺延到下一个可用端口，二维码与广播地址同步更新，无需手动配置。换 Wi-Fi、插网线后也会自动复检并刷新。

1. **启动程序**：运行 `main.py`，程序会自动启动本地服务器
2. **连接移动设备**：
   - 确保移动设备和电脑连接到同一 Wi-Fi 网络
   - 在移动设备上打开浏览器，扫描界面上的二维码
   - 或手动访问显示的服务器地址
3. **PC 互联**：
   - 程序会自动发现同一局域网中的其他 PC 设备
   - 在左侧设备列表中双击 PC 设备即可建立连接
4. **开始传输**：
   - 文字消息：在输入框中输入文字，按回车或点击发送按钮
   - 文件传输：点击文件按钮选择要发送的文件或文件夹

## 📁 文件结构

```bash
main.py              # 程序入口
config.json          # 配置文件（自动生成）
requirements.txt     # 依赖清单
app/                 # 核心模块
├── __init__.py
├── server.py        # Flask 服务器 + SocketIO + 移动设备网页
├── config.py        # 配置文件读写管理
├── signal.py        # Qt 信号定义
├── utils.py         # 工具函数（IP 获取、文件大小格式化等）
├── discovery.py     # UDP 广播设备发现
├── pc_client.py     # PC 客户端连接模块
└── ui/
    ├── __init__.py
    ├── main_window.py       # 主窗口界面
    └── device_selector.py   # 设备选择对话框
```



## 🛠️ 技术栈

- **后端**: Python 3 + Flask + Flask-SocketIO + Gevent
- **前端**: HTML5 + CSS3 + JavaScript（移动设备网页）
- **桌面界面**: PyQt5
- **二维码**: qrcode + Pillow
- **设备发现**: UDP 广播

## 📱 移动设备功能

移动设备网页支持：
- 文字消息发送和接收
- 文件上传（带进度条）
- 文件夹上传（保留目录结构）
- 文件下载
- 连接状态实时显示
- 关于页面（含隐私声明和免责声明）

## 🖥️ PC 互联功能

- 自动发现局域网中的 PC 设备（UDP 广播）

- 多 IP 选择（支持多网卡环境）

## 🔒 隐私与安全

**重要声明：**

- ✅ 本软件仅在本地局域网内传输数据
- ✅ 不上传任何数据到远程服务器
- ✅ 不收集、不窃取用户隐私信息
- ✅ 不监控、不记录用户剪贴板内容
- ✅ 无后台运行、无隐蔽数据传输
- ⚠️ 为保持「扫码即连」，默认不做密码校验：同一 Wi-Fi 内、知道地址的设备可访问页面与已发出的文件链接，请在可信网络中使用
