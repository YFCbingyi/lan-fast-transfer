# 📡 局域网双向传输工具

一款简洁高效的局域网文件传输工具，支持电脑与手机之间的实时消息和文件互传。

## ✨ 功能特性

- 📱 **跨设备通信**：支持电脑与手机之间的双向消息和文件传输
- 🌐 **局域网传输**：仅在本地局域网内传输数据，无需互联网
- 📤 **大文件支持**：支持大文件高速传输，带实时进度条显示
- 🔄 **实时消息**：支持文字消息的实时发送和接收
- 📲 **扫码连接**：手机扫码即可快速连接，无需手动输入地址
- 🔒 **隐私安全**：不上传任何数据到远程服务器，保护用户隐私

## 🚀 快速开始

### 前置条件

运行前请确保已安装以下依赖：

```bash
pip install flask flask-socketio gevent qrcode Pillow requests PyQt5
```

或者使用 requirements.txt：

```bash
pip install -r requirements.txt
```

### 运行方式

```bash
# 直接运行
python lan_chat.py

# 可选：指定下载路径
python lan_chat.py --download-path /path/to/downloads
```

### 使用步骤

1. **启动程序**：运行 `lan_chat.py`，程序会自动启动本地服务器
2. **连接手机**：
   - 确保手机和电脑连接到同一Wi-Fi网络
   - 打开手机浏览器，扫描界面上的二维码
   - 或手动访问显示的服务器地址
3. **开始传输**：
   - 文字消息：在输入框中输入文字，按回车或点击发送按钮
   - 文件传输：点击文件按钮选择要发送的文件

## 📁 文件结构

```
lan_chat.py          # 主程序文件
config.json          # 配置文件（自动生成）
download/            # 默认下载目录（自动创建）
LanChatUploads/      # 上传临时目录（自动创建）
README.md            # 项目说明文档
```

## 🛠️ 技术栈

- **后端**: Python 3 + Flask + Flask-SocketIO
- **前端**: HTML5 + CSS3 + JavaScript
- **桌面界面**: PyQt5
- **二维码**: qrcode + PIL
- **图标**: Emoji 表情符号

## 📱 手机端功能

手机端网页支持：
- 文字消息发送和接收
- 文件上传（带进度条）
- 文件下载（带进度条）
- 连接状态实时显示
